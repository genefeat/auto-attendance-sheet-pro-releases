# Auto Attendance Sheet Pro — Windows 版

勤怠記録アプリ **Auto Attendance Sheet Pro** の Windows 版配布ページです。
iPhone / Android 版で Pro（サブスクリプション）を購入したアカウントでログインして使用します。

## ダウンロード

👉 **[最新版をダウンロード](https://github.com/fu-lab-jp/auto-attendance-sheet-pro-releases/releases/latest)**
（`AutoAttendanceSheetPro.exe` をダウンロードして実行するだけ。インストール不要）

## 動作環境

- Windows 10 / 11（64bit）

## 使い方

1. `AutoAttendanceSheetPro.exe` を起動
2. iPhone / Android で Pro を購入したアカウント（メール・パスワード）でログイン
3. 勤怠データ・設定が iPhone / Android と自動で同期されます
   - Windows の Event Log（ロック/アンロック）から出退勤を自動検出する機能つき

## 注意

- Windows 版の利用には **Pro（サブスクリプション）** が必要です。購入は iPhone / Android アプリから。
- 初回実行時に Windows SmartScreen の警告が出る場合は「詳細情報」→「実行」を選択してください。
