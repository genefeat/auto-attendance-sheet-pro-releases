# Auto Attendance Sheet Pro — Windows 版

勤怠記録アプリ **Auto Attendance Sheet Pro** の Windows 版の配布ページです。
iPhone / Android 版で Pro（サブスクリプション）を購入したアカウントでログインして使用します。

## ダウンロード

👉 **[最新版をダウンロード](../../releases/latest)**
（`AutoAttendanceSheetPro_Setup_<バージョン>.exe` をダウンロードして実行します。以前の版を入れている場合も、そのまま上書きで更新できます）

## 動作環境

- Windows 10 / 11（64bit）

## 使い方

1. ダウンロードしたインストーラーを実行し、Auto Attendance Sheet Pro を起動
2. iPhone / Android で Pro を購入したアカウント（メール・パスワード）でログイン
3. 勤怠データ・設定が iPhone / Android と自動で同期されます
   - Windows のイベントログ（ロック/ロックの解除）から出退勤を自動で検出する機能つき

## 注意

- Windows 版の利用には **Pro（サブスクリプション）** が必要です。購入は iPhone / Android アプリから。
- 初回の実行で Windows SmartScreen の警告が出る場合は「詳細情報」→「実行」を選択してください。
